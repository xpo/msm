mSM

.md Slide Machine, un moteur de présentation minimal.
Écris tes slides en Markdown, présente-les partout.

Voir la démo Télécharger (macOS) Code source

La démo présente mSM avec mSM

Clique dans la démo, puis utilise les flèches (ou Espace). O pour la vue d'ensemble, ? pour l'aide.

Pourquoi mSM

Un fichier .md

Ton deck est du Markdown standard. Versionnable dans Git, éditable dans n'importe quel éditeur.

Trois runtimes

App macOS (LÖVE + Lua, signée et notarisée), runtime web autonome (un seul HTML), export HTML statique.

Mermaid inclus

Blocs ```mermaid rendus en desktop comme en web. Diagrammes, flowcharts, séquences.

Thèmes et animations

Fonds animés (mesh, aurora, grain, particles), transitions (fade, slide, push), Ken Burns sur les images.

Mode présentateur

Notes de speaker, vue mosaïque, laser pointeur, écran noir, auto-avance, timer, barre de progression.

Édition à chaud

Cmd-E pour éditer la slide en cours, Cmd-S pour sauver. Watcher automatique du fichier.

Installation

macOS, application desktop

Télécharge mSM.dmg depuis GitLab Releases, glisse dans Applications, lance. Signé Developer ID, notarisé Apple.

Web, sans installation

Ouvre msm.html dans un navigateur, glisse ton .md dessus. Ou passe l'URL du deck en query : msm.html?deck=mon-deck.md.

Export HTML autonome

Touche E dans l'app desktop : mSM produit un HTML unique contenant le deck, prêt à partager par email ou à publier.

Raccourcis principaux

  • → Espace : slide suivante
  • ← Backspace : slide précédente
  • O : vue d'ensemble (mosaïque)
  • F : plein écran
  • C : notes de speaker
  • L : laser pointeur
  • V : bascule slides visibles, slides cachées
  • H ou ? : aide complète
